Sparkplug message types

STATEA Primary Host's online/offline. None in this flow, so the gateway does not wait for one.
NBIRTHGateway session start: seq 0, bdSeq, Node Control/Rebirth.
DBIRTHA device introduced with all its metrics; one per device.
DDATAA reading. seq 0–255 (shared across the gateway) detects gaps; DeviceSeq removes duplicates.
NDATAGateway heartbeat (uptime).
DDEATHOne device lost: data acquisition failed to poll it 3 times in a row, or it was removed from the registry. The others are unaffected.
NDEATHGateway session ended, which takes all its devices offline with it.
NCMDA host application asks for a Rebirth when it is out of sync (none in this flow).
